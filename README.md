# Quiz-Detective

Quiz Detective is an interactive quiz game where players solve mysteries by answering questions, collecting clues, and earning XP.

## ✨ Features
- Mystery-solving quiz challenges
- Multiple-choice questions
- Lives and scoring system
- XP and detective ranks
- Custom SVG graphics
- Responsive design
- Progress saved using Local Storage

## 🛠️ Built With
- HTML
- CSS
- JavaScript
- SVG

## 🚀 How to Run
1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## 🎯 Purpose
To make learning fun through interactive quizzes, logical thinking, and mystery-solving challenges.

**Think like a detective. Solve every mystery!** 🔍
